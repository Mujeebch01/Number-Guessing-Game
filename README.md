Number-Guessing-Game

🎮 Number-Guessing-Game .  A simple console-based Number Guessing Game built using C++. The player guesses a secret number, and the program provides hints like TOO HIGH or TOO LOW until the correct number is guessed.

✨ Features

🎯 Number Guessing Game

📈 TOO HIGH / TOO LOW hints

🔁 Loop until correct guess

🔢 Attempt counter

🧠 Beginner-friendly project

🛠️ Technologies Used

C++

iostream

📚 Concepts Used

do-while loop

if-else if conditions

User input/output

Variables & counters

▶️ How To Run

Open the project in any C++ compiler

Compile and run the program

Start guessing the number

📋 Sample Output

Guess the number : 50

TOO LOW!

Guess the number : 90

TOO HIGH!

Guess the number : 85
